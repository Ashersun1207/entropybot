# Guarded HTTP collection reader

Baseline `3f0a9b152`, branch `codex/engineering-collection-http`, sole writer in `.worktrees/engineering-collection-http`. This delivery contains only `server/web-collection-http.ts`, its adjacent test, and this document. Parent independent review and serial integration remain pending. Production index dispatch, report UI, stable HTTP request identity and automatic host recovery remain later work.

`createCollectionHttpReader()` returns the existing `CollectionOptions.read(source, signal, pageBytes)` function. It reuses `collectionUrl`: HTTP/S only, no URL username/password, normalized URL with fragment removed. Text is literal UTF-8; no HTML executes. Only status **200** is accepted; other successful codes may describe an empty/partial/non-page response and are conservatively refused. Encoded responses are refused; the default transport requests identity encoding and does not decompress.

Every hostname redirect hop resolves anew through an injectable resolver; IP literals are checked directly. A fresh own-address snapshot and existing `addressClass`/`ownAddresses` from `server/browser/egress/policy.ts` check the DNS set, with `namesThisMachine` distinguishing named loopback rebinding. Any non-public result refuses the target: loopback, this-machine, private, link-local, metadata or reserved. No classifier/range table, allow-list, browser policy or dependency is changed. Private/local networks are closed for this reader, independently of browser desktop allowances. Empty DNS results and address/family mismatch also refuse.

The default core Node HTTP/S transport retains the original URL authority, pins lookup to one approved address, and supplies its explicit family to prevent automatic alternate-family selection. Host and TLS certificate identity remain the URL's identity. `agent:false` avoids pooled connection reuse. There is no proxy configuration, cookie/credential forwarding, automatic redirect handling or fallback/retry to another address. Injected requests must obey the same pinning, authority and no-redirect contract. Tests inspect default adapter options through fake Node request entry points and invoke its lookup callback without a socket.

Finite limits: `pageBytes` 1–1,000,000; local timeout default 15 seconds, configurable 1–60,000 ms; redirect limit default five, configurable 0–5 (at most six requests). Redirect bodies are destroyed without iteration; the next canonical target is validated before its request. Chunks exceeding remaining bytes are refused before copying into one fixed `pageBytes` buffer. Content-Length can reject early but cannot relax that streaming bound. UTF-8 replacement expansion is checked against the output allowance. Socket/parser/OS buffers and finite decoder allocations are separate from retained body bytes; this is not a process-memory or OS-I/O sandbox.

Caller cancellation and the local timer cover DNS, transport, all redirects and body through a combined signal and bounded await. Responses are destroyed on success, rejection and cancellation; late transport responses are destroyed before iteration. Native DNS lookup cannot be forcibly interrupted, but a late result cannot start a request after scope closure. An injected implementation ignoring abort may keep its own work pending; the reader cannot forcibly reclaim arbitrary injected work. Errors propagate without conversion to empty text. collectWeb retains its durable reservation/unknown-outcome behavior and refuses automatic resend after reader failure.
