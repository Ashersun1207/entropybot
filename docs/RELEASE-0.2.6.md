# Entropybot 0.2.6

状态：本地候选准备，尚未构建、安装或公开发布。本候选包含 0.2.5 真实凭证迁移后的源码加固；不能把先前 0.2.5 的安装结果当成本候选验收。

- 旧凭证读取前默认取消的原生确认，避免内部 CLI 无提示输出凭证。
- 迁移写入在 await 后复核源库，失败不覆盖其他进程的新写入。
- 子进程控制失败、超时及异常清理等待退出确认；无法确认时保留临时目录和证据。
- 新增迁移、回滚、清理和正式签名准备的持续回归门槛；停用隔离保证不足的旧 Keychain 注入探针。
- 正式签名/公证入口与构建来源记录分离，缺少证书配置时明确停止，不把本地 ad-hoc 候选冒充正式签名产物。
- 安装包排除 Node 测试文件与 Python 凭证验收夹具，打包后核对实际 ASAR 内容。

本机安装前保留完整 0.2.5 应用备份和旧加密凭证库；用户真实 Keychain 不做拒绝/锁定故障实验。故障与降级演练使用合成数据和独立测试环境。

用户尚未开通 Apple Developer Program，当前无可用 Developer ID 身份；正式签名、公证和在这些条件完成后的公开发布暂不可执行。本地候选仍使用现有 ad-hoc 模式，重建后的系统授权需要重新验收。

全仓回归、候选构建和安装结果由外层 `gorkbot/docs/release-0.2.6-validation.md` 记录；未完成的步骤不能标注为通过。
