# README product screenshots

The four `readme-workspace-*.png` images are captures of Entropybot's real App renderer and original product styles, using the accepted development source `d075fdf4a77103f84e3998e3b001c10322957485`.

- Chinese and English each have daylight and midnight versions. The root READMEs use `<picture>` to follow the reader's light/dark preference.
- Captures use the full interface mode at 1120 × 720 CSS pixels and device scale 2, producing 2240 × 1440 PNGs. The workspace is not redrawn, composited or restyled for the image.
- The scene compares two synthetic book club documents, asks for a date decision and returns a preparation checklist. Assistant names, tool results and replies are synthetic, generated through an isolated fixture with a fake engine.
- No personal chats, memories, account credentials or live model responses are included. Execution times visible in the UI belong to the fixture and are not performance measurements of a real model.
- These are development UI captures, not evidence that the public desktop download contains every displayed feature. See the release notes for the downloadable version. Browser renderer captures do not establish native operating-system window behavior.

Keep future README images representative of the product: capture the current accepted renderer, preserve the actual sidebar and composer, use clear synthetic content, avoid excess empty space, and check both languages and themes before publishing.
