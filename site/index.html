安装、备份与更新说明 ↗

还有几个问题。

开始使用前，需要准备什么？

当前公开下载适用于 macOS Apple silicon。安装后需连接你选择的模型或执行引擎，具体服务可能收费。本地使用无需注册网站账号；更新前请退出应用并备份工作区与桌面配置。

本地优先，意味着完全离线吗？

不意味着完全离线。记忆与索引保存在本机，但远程模型和云端 embedding 请求仍会发送到你配置的服务。数据处理范围和费用以所选服务为准。

纠正一条记忆，会删除所有旧记录吗？

不会。修订当前记忆不等于删除聊天、摘要或备份里的全部副本。请按你要管理的数据范围分别查看与处理。

截图里的界面，就是下载到的版本吗？

页面使用真实应用界面与合成示例内容。界面和能力可能来自未发布候选；下载内容、可用平台和功能以公开 Releases 为准。目前公开版是 0.2.3，0.2.6 尚未公开发布。

为什么 macOS 可能提示需要批准？

当前公开安装包采用 ad-hoc 签名，未经 Apple 公证。macOS可能要求在隐私与安全设置中批准，应用身份变化也可能触发权限提示。安装前请阅读发布说明；正式 Developer ID 签名与公证尚未完成。
